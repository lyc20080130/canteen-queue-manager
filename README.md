# 食堂排队管家 · canteen-queue-manager

> 不做点餐，不做外卖——只让「排队」这件事变得**可预期、可支配**。

温州大学食堂中午排队问题的解决方案。核心理念：把「不知道要等多久」的焦虑，变成「我知道还有 8 分钟，可以先去买瓶水」。

## 解决什么问题

午间高峰，食堂窗口队伍长且**不可预测**。学生站在队里不知道：
- 前面还有多少人、大概还要等多久
- 换一个窗口是不是更快
- 现在走过去，来得及吗

结果是两个极端：要么提前很久去（浪费时间），要么看到队伍就放弃（流失就餐）。

## 我们做什么 / 不做什么

| ✅ 做 | ❌ 不做 |
|---|---|
| 各窗口实时/预测等待时长 | 点餐、下单 |
| 错峰建议（几点去人最少） | 外卖配送 |
| 队伍长度可视化 | 支付、结算 |

## 团队协作规范

- **主分支**：`main`，保持随时可运行
- **提交前**：先 `git pull --rebase`，避免无意义 merge 提交
- **分支命名**：`feat/功能名`、`fix/问题描述`
- **提交信息**：中文可读，用 `feat:` / `fix:` / `docs:` / `chore:` 前缀

```bash
git checkout -b feat/queue-display   # 开新分支
git add .
git commit -m "feat: 添加窗口等待时长卡片"
git push -u origin feat/queue-display
```
